# v1.0.12 界面调整验证范围

本版将手动流量与 API 余量查询合并到设置页“刷新流量与 API 余量”按钮，左侧仅展示流量；开机启动和日志开关同排。自动流量刷新仍为 8 小时，不自动查询 API 余量。查询服务、协调器、凭据存储和现有测试源码未修改。

## 检查与证据

- 现有完整隔离回归 867 项通过，覆盖服务解析、凭据加密、缓存、冷却、限流、取消和并发；不将这些服务测试称为新 UI 事件测试。
- 标准 x64 Release 成功，0 警告、0 错误，包含 XAML 编译及默认分析器。
- XAML 结构和事件引用检查通过：左侧无手动查询控件；设置页有单一合并刷新入口及结果；启动/日志开关共用横向容器；Click 方法存在，手动路径先刷新流量再查询配额。
- UI 新事件处理的分支覆盖率和变异得分未测量。无可执行页面入口的便携测试不包含 WinUI，不套用历史服务指标。本版为 UI 入口及布局调整，不增加测试依赖或借机提取业务模型。

相关修改完成 24 项异味及异常、资源、并发、凭据安全源码检查：窗口/页面代码后置与事件方法仍有规模倾向，未据此执行额外重构。忙碌标记、finally 恢复按钮及凭据版本检查避免重复操作和旧账户结果覆盖。其他分类未发现有实际意义的新异味；不因存在循环、数据记录或可变 UI 字段直接判定设计缺陷。

## 使用和验收边界

合并按钮使用已保存账户，并沿用两个端点各自的缓存/冷却与共享 HTTP 限流保护；不承诺每次点击都发出两个网络请求。若自动流量查询正在进行，复用既有串行和缓存保护。结果显示原始更新时间，配额仍为点数快照，不等同于调用次数。保存凭据保留原有流量查询行为；只有手动合并刷新会查询配额。

实际界面布局、焦点、导航期间等待及真实搬瓦工账户尚未系统级联调；结构检查不能替代像素和交互验收。没有修改真实代理、路由、DNS、自启动或日志开关。测试仅使用虚构凭据、模拟后端、本地回环及临时目录；Windows 加密用例在获准访问用户加密接口的进程中执行。

隔离与编译检查通过，现场验收未验证。发布过程另外执行干净打包、ZIP/清单校验及隔离更新器交接检查。原始日志和源码指纹保存在本地忽略目录 `artifacts/validation/combined-refresh-20261020/`，包括 report.md、layout-check.log、regression-outside-sandbox.log、release-build.log、source-hashes.json 及发布构建/校验日志；环境限制原始日志一并保留。

复现：`dotnet run --project Tests/UpdateTests.csproj -c Release`；`dotnet build singC.csproj -c Release -p:Platform=x64 -r win-x64`；`python artifacts/validation/combined-refresh-20261020/check_layout.py`。环境为 Windows x64、.NET SDK 8.0.425。操作入口和模块边界见 [README](../README.md#bandwagonhost-quota-query)、[架构图](ARCHITECTURE.md)。
