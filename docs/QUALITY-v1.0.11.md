## 行为与验证边界

- `getRateLimitStatus` 仅由侧栏手动按钮触发，返回的是点数，不是精确剩余调用次数；不假设每次请求成本或服务商精确重置时刻。
- 缓存及冷却按凭据对分区，仅在当前进程内保存；重启会重新开始。已知耗尽后的暂停时间是本机保守策略，后续手动正数快照可解除。
- 本地查询仍受本机系统代理、TUN 和路由影响。凭据以 Windows DPAPI 为当前用户加密，不宣称防止同用户权限恶意程序读取内存。
- 所有测试只使用虚构密钥、模拟后端/现有本地回环测试及临时目录；未访问真实搬瓦工账户，未改动真实系统代理、路由或 DNS。Windows 加密用例在可访问用户加密接口的进程中执行。
- 真实 API 可达性、账户点数恢复、界面布局/焦点、跨进程冷却和时钟跳变未系统级实测；UI 仅有源码及编译检查，未报告其覆盖率或变异得分。

编译与隔离检查通过，现场验收为未验证。发布流程另执行干净打包、真实 ZIP/清单验证及隔离更新器交接检查；不以这些检查替代真实账户联调。
